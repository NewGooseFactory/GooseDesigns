LLM inference engine for agentic workloads

Control in C++.Execution in Python.

TokenSpeed splits the engine in two. A C++ state machine owns request lifecycles and KV cache state, checked at compile time. A Python execution plane keeps iteration fast.

Two planes, one engine.

Most inference engines mix scheduling and execution in one language. TokenSpeed gives each half the language that suits it: types where mistakes are expensive, Python where change is constant.

Control plane C++

A finite-state machine. Request lifecycle, KV cache ownership and overlap timing are encoded as states, and safe KV reuse is enforced by the type system at compile time, not at runtime.

Execution plane Python

The layer researchers and engineers change most. Writing it in Python keeps development fast and the cognitive load low.

Kernels as a subsystem

Pluggable and layered: a portable public API, a central registry and selection model, and a plugin mechanism for different accelerators. The project counts its MLA kernel on Blackwell among the fastest.

A lean entry point

An SMG-integrated AsyncLLM handles requests on the CPU side with low overhead.

“TokenSpeed is an open source LLM inference engine and the first to separate the control plane from the execution plane.”

The PyTorch Foundation, welcoming TokenSpeed to the PyTorch Ecosystem Landscape

Neutral ground.

TokenSpeed is backed by the non-profit LightSeek Foundation, not a commercial company, with hardware and engineering support from vendors including NVIDIA and AMD.

The README calls it the Switzerland of open-source LLM inference engines.
