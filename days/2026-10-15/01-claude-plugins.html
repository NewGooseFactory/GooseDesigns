02 · the slug

A plugin's name never changes.

The name in a marketplace entry is an immutable slug. People have the plugin installed under it, and renaming it breaks their install with a plugin-not-found error.

To change the label people see, set displayName. If a rename really cannot be avoided, add it to the renames map, and existing installs move over on their next sync.

03 · anatomy

One file is required. The rest is up to you.

Every plugin follows the same folder structure. A source repository that ships only SKILL.md files can still be listed as a skill bundle, with its skills declared in the marketplace entry instead.
