Fit check, not a leaderboard

Hundreds of models. One command to find what runs on your hardware.

The question is never which model is best. It is which model your machine can actually hold. llmfit answers that one, across hundreds of models and providers.

One command

No config file to fill in before the first useful answer. You run it, it reads the machine, it prints the list.

Hundreds of providers

The catalogue is the point. A tool that only knows the models you already run tells you nothing new.

Written in Rust

A single binary you drop next to the runtimes you already have installed.
