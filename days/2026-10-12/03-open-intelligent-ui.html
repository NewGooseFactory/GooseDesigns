Router, not guesswork

Jev picks the renderer for each turn: A2UI for basic tables, Open Generative UI for charts, diagrams, calculators and maps. Provider failures are surfaced instead of silently swapped.

Sandboxed by design

Generated HTML, CSS and JavaScript run in an isolated iframe. A follow-up you click goes through a validated host bridge and starts a new agent turn.

Your keys stay yours

Keys live in browser memory until refresh or Clear keys — never in browser storage — and stay out of chat state and checkpoints.
