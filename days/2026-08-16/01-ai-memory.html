Memory that outlives the session

Long term memory for agent coding CLIs.

One store your tools read and write. Hand off between different agent vendors instead of re-explaining the codebase every time you switch.

Written in Rust

A single binary next to the CLIs you already run. No daemon to babysit, no editor plugin required.

Vendor neutral

The store does not belong to one agent product. That is the whole point of the handoff.

Long term by default

Context survives the session that produced it, so the next run starts from what you already decided.
