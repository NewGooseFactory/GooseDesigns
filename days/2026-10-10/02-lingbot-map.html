Keep the first frames, the last few, and six tokens of everything between.

LingBot-Map is a feed-forward 3D foundation model that reconstructs scenes from a video stream. Its Geometric Context Transformer attends to three kinds of context — an anchor, a pose-reference window and a trajectory memory — so the streaming state stays compact over sequences longer than 10,000 frames.

coordinate & scale grounding

Anchor context

Monocular reconstruction is scale-ambiguous, so the first n frames attend fully to each other and fix the scale. Every later frame attends to them as fixed references.

dense local geometry

Pose-reference window

A sliding window of the k most recent frames keeps full image tokens, so each new frame registers against dense, nearby views.

long-range drift correction

Trajectory memory

Every other frame keeps six tokens with temporal position encodings — a lightweight, ordered record of the whole trajectory that helps correct accumulated drift.

A reference frame, a local window and a global map — the SLAM recipe, replaced with end-to-end learned attention.Paraphrasing the paper’s own motivation
