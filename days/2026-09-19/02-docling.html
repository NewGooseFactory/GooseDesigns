How it is meant to run

Locally when it matters

Local execution is offered for sensitive data and air-gapped environments.

Inside the pipeline you already have

Integrations for LangChain, LlamaIndex, Crew AI and Haystack, plus an MCP server.

Or as a plain command

A CLI and an API server for running it as a service.
