The RAD Debugger Project · alpha

A native, multi‑process, graphical debugger.

User-mode and graphical. Today it supports local-machine Windows x64 debugging with PDBs; native Linux debugging and DWARF debug info come next.

From the README

ctrl implements asynchronous process control, stepping, and breakpoints for all attached processes. Runs in lockstep with attached processes. When it runs, attached processes are halted. When attached processes are running, it is halted.

Roadmap

as the project lays it out
nowAlpha battle-testing

Rock-solid local x64 Windows debugging: debug info conversion and loading, process control, stepping, evaluation, and a robust frontend.

nextLocal x64 Linux debugging

Port demon, an ELF unwinder in ctrl, DWARF-to-RDI, plus the render, font and OS layers.

and beyondFurther directions

Remote debugging, other architectures, and a better visualization engine.

The debugger is in alpha. The project asks for issue reports with whatever you can gather — dump files with the build you used, steps to reproduce, test executables.
