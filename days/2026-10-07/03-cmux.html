Ghostty-based macOS terminal · for AI coding agents

Tell which agent needs you. Across every split and tab.

cmux is a native macOS app built on libghostty, with vertical tabs and notifications for coding agents. When one is waiting, its pane gets a blue ring and its tab lights up in the sidebar — next to the branch, PR, directory and ports it belongs to.

$ brew tap manaflow-ai/cmux
$ brew install --cask cmux

cmux is a primitive, not a solution. It gives you a terminal, a browser, notifications, workspaces, splits, tabs, and a CLI to control all of it. What you build with the primitives is yours.
Native macOS

Swift and AppKit, not Electron, rendering through libghostty.

Your Ghostty config

Themes, fonts and colors carry over from ~/.config/ghostty/config.

Hooks or escape codes

Rings fire on OSC 9/99/777, or from cmux notify in your agent’s hooks.

Scriptable

A CLI and socket API for workspaces, splits, keystrokes and the in-app browser.
