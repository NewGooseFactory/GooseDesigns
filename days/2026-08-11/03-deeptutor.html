DeepTutor is lifelong personalized tutoring. The word lifelong is the whole design constraint, because a tutor who forgets you is starting over every session.

Record content is illustrative. The project describes itself as lifelong personalized tutoring.

The claim

Personalization without memory is a survey you retake every week.

Why lifelong

Most tutoring systems personalize inside a session. They read the last few answers, adjust difficulty, and then the context ends.

A lifelong record changes which mistakes are interesting. The second time a learner stalls on the same idea is a pattern, and it can only look like one if the first time was written down.

That also changes what the system owes the learner. A record held across terms is worth explaining and worth correcting when it gets a learner wrong.

For anyone building agent memory, tutoring is a clean version of the problem, because the ground truth arrives later and repeatedly.
