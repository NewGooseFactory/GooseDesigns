03

Seven verbs.

addInstall skills from a repository, URL or local path
useUse one skill without installing
listList installed skills (alias: ls)
findSearch for skills interactively or by keyword
updateUpdate installed skills to latest versions
removeRemove installed skills from agents
initCreate a new SKILL.md template

add accepts owner/repo, GitHub, GitLab and Azure Repos URLs, any git URL, a local path, or a direct link to a SKILL.md or archive.

04

A skill is a folder with one file.

---
name: my-skill
description: What this skill does and when to use it
---

# My Skill

Instructions for the agent to follow when this skill is activated.

name and description are required. Set metadata.internal: true to hide a work-in-progress skill from normal discovery.

The CLI collects anonymous usage data. Set DISABLE_TELEMETRY=1 or DO_NOT_TRACK=1 to turn it off.
