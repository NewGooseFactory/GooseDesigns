Zero-server

Your repository becomes a graph without leaving the tab.

Drop in a repo or a ZIP and get an interactive knowledge graph with a Graph RAG agent built in. The whole thing runs client-side, which is the part that decides whether you can point it at work code.

Zero-server is the claim

A code intelligence tool that never uploads is the difference between a demo on a public repo and something you can run against a private one.

The agent is inside the graph

Graph RAG ships with the graph rather than beside it, so the retrieval structure and the thing querying it are the same artifact.
