Drop one in

A brand system, reduced to a file an agent reads.

The verb in the description is drop, which is a lower bar than configure or install. A markdown file goes in the repo root and the coding agent picks the styling up from there, so design decisions live in the same place as the code that renders them.

Markdown is the format choice

A design token file would be machine readable and unreadable by people. Markdown keeps the brief in the form a designer would have written anyway.

Matching is the contested word

Generating a UI is easy. Generating one that matches a named brand system is the claim, and nothing in the description says how close counts as matching.

What is not on this page
