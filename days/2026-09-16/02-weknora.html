Three ways to reach the same corpus: ask it a quick question, let an agent work a multi-step task, or let it distil itself into an interlinked knowledge base you can edit.

Mode one

Quick answers

RAG-based question and answer for everyday lookups.

Mode two

Agent

A ReAct agent that orchestrates retrieval, MCP tools, sandboxes and web search for multi-step work.

Mode three

Wiki

Agents distil raw documents into a self-maintaining markdown knowledge base with a knowledge graph.
