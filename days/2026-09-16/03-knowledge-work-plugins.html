A plugin is a manifest, a set of tool connections, the commands you invoke, and the skills that fire on their own. Markdown and JSON, no build step.

Inside one plugin

Published structure

.claude-plugin/plugin.json

The manifest. What this plugin is.

.mcp.json

The connectors. Which outside tools the role depends on.

commands/

What you invoke. Slash commands you trigger deliberately.

skills/

What fires on its own. The domain knowledge drawn on when relevant.

The split between the triangle and the bar is the whole design: one is a decision you make, the other is a default you set once.
Every component is file-based, so a plugin is readable before it is trusted.
