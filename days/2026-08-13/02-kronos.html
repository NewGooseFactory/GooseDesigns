SHIYU-CODER / KRONOS
Open source foundation model
Candlesticks as a sequence

A K-line is a token.

Kronos is the first open-source foundation model for financial candlesticks, trained on data from over 45 global exchanges. Calling a chart a language is a modeling claim: it says the next bar is predicted the way the next word is.

Shapes are illustrative. The point of the strip is that a bar is a discrete symbol before it is a price, which is what makes the sequence tokenizable at all. Kronos was accepted to AAAI 2026.

Scope

Over 45 exchanges

Training across many venues is what separates a foundation model from a model fit to one ticker on one desk.

Claim

The language framing

Naming candlesticks a language commits to next-token prediction, so the model is judged on continuation.

Access

Open source, first

The project states it is the first open-source foundation model for K-lines, so the weights are the argument.
