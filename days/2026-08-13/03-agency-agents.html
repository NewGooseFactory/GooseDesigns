The roster is

Agency Agents collects specialized experts, each with its own personality, processes, and proven deliverables. What changed is distribution: a native app browses the whole roster and installs it into your coding tool with a click.

A prompt is easy to copy. A roster with a shared shape is what makes the twentieth agent as predictable as the first.

Personality

Voice is a spec

Giving each agent a stated personality makes its output recognizable, which is how you notice when one drifts.

Processes

A repeatable path

The description pairs every specialist with a process, so the agent is a procedure you can audit rather than a mood.

Deliverables

Something lands

Naming a deliverable per agent sets the finish line, and a finish line is what turns a chat into work.
