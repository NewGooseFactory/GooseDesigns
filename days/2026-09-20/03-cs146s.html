Repository setup

Python 3.12
01

Install Anaconda

open a new terminal so conda is on your PATH
02

Create the environment

conda create -n cs146s python=3.12 -y
03

Install Poetry

curl -sSL https://install.python-poetry.org | python -
04

Install dependencies

poetry install --no-interaction

Four commands, reproduced from the repository's own setup section.
The steps are documented as working with Python 3.12, run from the repository root inside the activated environment.

Why read coursework

A problem set is a specification with an answer key attached. Reading how a course frames the work of modern software development is a different signal from reading a framework's marketing page, and this one is public.
