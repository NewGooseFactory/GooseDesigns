Executable porting · Linux and Windows

No emulator.
No separate runtime.

AnyPS5 relinks an executable into the target system’s native format and supplies implementations of the system prx libraries for dynamic linking. The converted program runs as a normal process and calls those native libraries.

How a program is ported

from docs/dev/ARCHITECTURE.md
01 · relinkNative executable

The relinker reads imports by NID, checks syscalls, filters unused NIDs and builds a SysV dynamic section, then patches an ELF for Linux or a PE for Windows.

02 · linkNative libraries

Each library in core/libs/prx builds as a shared library with its exports renamed to their NIDs. The OS loader binds imports by NID.

03 · recompileSPIR-V shaders

The shader recompiler produces SPIR-V, validated with SPIRV-Tools when built with ANYPS5_ENABLE_SPIRV_TOOLS.

Fails loudly

Unsupported or unexpected states strictly throw std::runtime_error. what() is printed to stderr and the process terminates.
