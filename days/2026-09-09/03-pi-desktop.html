Local-first is the whole appeal

A coding agent that keeps the repository, the keys, and the history on your machine removes the question of what a service retains. It also puts every one of those things within reach of anything running locally.

Rust core plus Electron shell is a common split

The pattern gives you a fast host process and a UI toolkit people already know. Naming both tells a reader roughly where each kind of bug will live.

What is not on this page

No plugin API, no permission model, no sandbox, no install source. The trending description names four layers and no boundaries between them.
