Three acronyms, one shared object

Design, simulate, machine. Same geometry, three different questions.

CAD, CAE, CAM. Each one asks something different of the same part: what shape is it, will it hold, and can a machine cut it. A skill pack that names all three is claiming the model can move between those questions without losing the object.

What each acronym asksShape only, dimensions omitted
CADdesign

What shape is it. The output is geometry with tolerances and a bore that either exists or does not.

CAEsimulate

Will it hold. The output is a field over the same geometry, and the answer changes with the material.

CAMmachine

Can a machine cut it. The output is an ordered path, and order is the part a language model has to get right.

what survives all threethe geometry no format, no kernel, no unit published

CAM is the hard one for text

Design and analysis tolerate an approximate answer that a human corrects. A toolpath runs on a machine holding a cutter, and a wrong order is scrap or a broken tool.

Library, not application

The description says a library of agent skills, which puts this inside whatever CAD tool you already run rather than asking you to move to a new one.
