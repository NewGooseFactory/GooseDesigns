Agent skills for Android development

Written where the evals say models fall short.

30 skills across 18 areas of Android development, built on guidance from developer.android.com. They focus on workflows where evaluations show LLMs underperform, and deprioritize the areas models already handle well.

Activation

Ask for the outcome. The agent picks the skill.

Your agent activates installed skills that are relevant to the task. You prompt for the result, not the skill.

you › Make my app UI edge-to-edge.
agent › using system/edge-to-edge

As an agent plugin

Or install the whole set as a plugin.

The repository is also a plugin marketplace for Claude Code and Codex. With no agent folders and no --agent flag, the CLI installs for Gemini and Antigravity.

# Claude Code
/plugin install android-skills --marketplace android/skills

# Codex
codex plugin marketplace add android/skills
codex plugin add android-skills@android-skills

AI can make mistakes, so always double-check the results. Public contributions are not accepted at this time; file an issue for feedback or skill requests.
