Procedural knowledge for research agents

Working code is not a defensible analysis.

An agent asked to analyse an experiment will usually return code that runs. Whether the analysis holds up depends on procedural choices: which test the field accepts, which identifier namespace is authoritative, and which caveats must accompany a result. This library writes those choices down.

What the paper measured

The cost of a library is paid in context.

The paper measures two properties of the documentation itself, against a 200,000-token context window. Together they show why a skill's instructions load only when a task calls for them.

Descriptions stay small enough to keep resident. Full references do not, so they load on demand.

“We report no task-level evaluation and no host selection rate.”

From the paper’s abstract

The caveat, stated

Both measurements describe the documentation, not the science. Whether agents produce better analyses with these skills, and how often a host actually selects a skill, are left unmeasured, and the paper says so in its abstract.

A library about caveats that opens with its own reads as a method, not a pitch.

One choice, written down

Code that runs, off by one.

Genomic intervals come in several conventions, and code that mixes them still runs. The Genomic Coordinates skill exists to catch that before it reaches a result.

Genomic Coordinates

Which identifier namespace is authoritative

Converts intervals across conventions, normalises variant representations, and catches 0-based vs 1-based and assembly or contig-naming mismatches before they corrupt an analysis.

Install

Install what you need. Read it first.

Skills can run code and steer your agent. The project asks you to install only the skills you need, not the whole collection.

# one skill, with the GitHub CLI
gh skill install K-Dense-AI/scientific-agent-skills scanpy

# pin a release for reproducible installs
gh skill install K-Dense-AI/scientific-agent-skills --pin v2.71.0

# scan a third-party skill before you install it
skill-scanner scan /path/to/skill --use-behavioral

Security disclaimer · from the README

Skills can execute code and influence your coding agent’s behavior. Review what you install.

  • Do not install everything at once.
  • Read the SKILL.md before installing.
  • Check the contribution history: K-Dense-authored skills have been through internal review.
