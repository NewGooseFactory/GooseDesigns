One call
instead of
a crawl.

When an agent needs to understand code it greps, globs and reads one file at a time, rebuilding call paths by hand. CodeGraph hands it the relevant source, the call paths between those symbols, and the blast radius of a change in one call — from a local SQLite graph that re-syncs on every file change.

01

Extract

A native Rust kernel parses source with tree-sitter grammars — functions, classes, calls, imports.

02

Store

Everything lands in a local SQLite database with FTS5 full-text search.

03

Resolve

Calls to definitions, imports to files, inheritance and framework patterns.

04

Auto-sync

OS file events, a two-second quiet window, incremental updates. Nothing to re-run.
