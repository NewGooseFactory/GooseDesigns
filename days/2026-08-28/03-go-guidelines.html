Six words

Style guides used to be written for people.

"Help AI coding agents write modern Go." The audience noun is the whole story. A guidelines repository from a tooling vendor that names agents as its reader is a different document from one aimed at a team, and it will be read differently: loaded, not skimmed.

Modern is a moving word

Every Go release changes what modern means. A guidelines document indexed to that word is committing to revision rather than to a fixed position.

Help, not enforce

The verb is soft on purpose. This reads as context an agent loads rather than a linter that blocks a commit, which is a different place in the toolchain.

A vendor writing for agents

JetBrains sells an IDE to humans. Publishing guidance aimed at agents is that company describing who else is now typing in its editor.
