Marketing is new on this board

Every other skill pack in today's top fourteen targets writing code or running agents. This one points the same file format at a department that has never had one.

The unit is transferable

A skill file is a text file with instructions. Nothing about that format is specific to programming, which is why it took about a week to cross into another discipline.
