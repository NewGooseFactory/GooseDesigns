Extensible server platform · TLS by default

Every site
on HTTPS.

Caddy is an extensible server platform that uses TLS by default.

The certificate work is the part you do not write: public names get certificates from ZeroSSL and Let’s Encrypt, internal names and IPs get a fully-managed local CA, and HTTP/1.1, HTTP/2 and HTTP/3 are all on by default.

“Nearly all of Caddy’s configuration is contained in a single config document … This makes managing your server config more straightforward and reduces hidden variables/factors.”— the README, on why the default can be trusted

JSON is the native config language; the Caddyfile, YAML, TOML, NGINX config and more arrive through config adapters. Two apps — tls and http — ship standard.
