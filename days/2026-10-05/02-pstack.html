A port that writes down every place it disagrees.

pstack is an opinionated Cursor skill stack that improves agent outcomes. This port carries it to other harnesses, tracks upstream, and declares each named policy fork in tools/forks.json — with a reason, a version and an upstream status for every row.

What you actually type

“Use poteto-mode to fix the search filter resetting when I change pages.”
  1. Reproduce the failure first.
  2. Investigate with how and why.
  3. Delegate the fix — bringing in architect first if it crosses a function boundary.
  4. Rerun the failing case.

What comes back

The fix and the failing and passing evidence — trimmed, per the tinted row above, to the assertion and the counts.

pstack has no server or telemetry. What its skills ask your agent to read, including session transcripts, goes to your model provider; scripts run locally.
