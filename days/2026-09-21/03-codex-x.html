What it is

A cross-platform desktop tool for the OpenAI Codex desktop app and CLI. It manages their configuration; it is not a model, an agent, or a replacement for either.

Four things in one window

As published

Prompt injection

Templates and your own Markdown prompts, each with its own toggle, in two modes: append to the existing prompt, or replace it.

Providers and logins

Named official Codex logins and third-party API providers, switchable, with connection checks.

Sessions

Local sessions synced, searched and grouped by project path, with deletion by item or project.

Skills, MCP and TOML

Skills and MCP entries enabled one by one, beside a view of config.toml and auth.json, with backups before important writes.

Capabilities are reproduced from the project's own feature table. No screenshots, template counts or download figures are invented.
Built with Tauri, MIT licensed, packaged for macOS, Windows and Linux.

The choice that matters

Append or replace. A prompt manager that only appends quietly grows your instructions until nobody knows what is in them. Offering both modes, with a per-prompt toggle, is what makes the current state knowable.
