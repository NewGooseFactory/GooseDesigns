The spec stops
being scaffolding

Spec Kit is an open-source toolkit for building software with any AI coding agent. Its claim is a reversal: specifications become executable, directly generating working implementations rather than just guiding them.

For decades code was king and the spec was scaffolding you built and discarded once the real work began. Flip that and the document you were going to throw away becomes the thing under version control.

The README describes a ready-to-use spec-driven process that you can replace with your own, extended through presets and bundles, and built to work with any AI coding agent rather than one vendor.

Executable

A spec that runs

Calling the spec executable is what makes it worth maintaining, because a document nobody runs goes stale in a week.

Agent-neutral

Any coding agent

Keeping the process separate from the agent means the artifact survives when you switch tools next quarter.

Organizational

Built for the whole team

Bundles and presets exist because a methodology only holds if the second engineer gets the same setup as the first.
