A warning-free build isn’t proof of modern SwiftUI.

Many older SwiftUI declarations are marked deprecated: 100000.0. These soft deprecations keep Xcode quiet, so the skill reviews the source for the mistakes LLMs actually make.

Specimen · six rules from references/api.mdstruck = what the model writes · blue = what the skill asks for
S-01color
.foregroundColor(.red).foregroundStyle(.red)

The rule the skill uses as its own example of a finding.

S-02soft-deprecated
.accentColor(.orange).tint(.orange)

Set the asset catalog’s accent color for an app-wide default.

S-03shape
.cornerRadius(12).clipShape(.rect(cornerRadius: 12))

Always the clip shape, never the old modifier.

S-04tabs
.tabItem { … }Tab(…) { … }

Always use the Tab API instead of tabItem().

S-05scroll
showsIndicators: false.scrollIndicators(.hidden)

Hide indicators with the modifier, not the initializer.

S-06localization
Text("Folder: " + name)Text("Folder: \(name)")

Interpolation keeps a localization key; string addition does not.

How a finding reads

// Before
Button(action: addUser) {
    Image(systemName: "plus")
}

// After
Button("Add User", systemImage: "plus", action: addUser)

Findings are organized by file, each naming the rule and showing a brief before and after. Report only genuine problems — do not nitpick or invent issues.
