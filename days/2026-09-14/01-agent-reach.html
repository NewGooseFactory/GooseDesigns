Reading access for your agent

One CLI.
Many front doors.

Your agent can already write code. This gives it a way to read and search public platforms without wiring up each one yourself.

The project describes itself as one CLI with zero API fees, MIT licensed, Python 3.10 or newer. Access to any platform still depends on that platform.
