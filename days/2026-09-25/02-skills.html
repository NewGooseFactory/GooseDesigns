Subscribe, or make them yours. Not both.

Two installers, two philosophies, and the project is blunt about the consequence: pick one, because installing both leaves you with every skill twice.

Installing both leaves you with every skill twice. Quoted from the project, because a setup instruction that names its own failure mode is worth putting above the fold.

Built against named failure modes

The agent did not do what I wantgrill-me / grill-with-docs
A grilling session before the work starts, so the misalignment surfaces in questions rather than in a finished diff.
The agent is far too verbosea shared vocabulary
The project frames this as the domain-language problem: an agent dropped into a project guessing at the jargon.

Stated stance

Small, easy to adapt, composable. The project positions itself against process frameworks that take control away and make bugs in the process hard to resolve, and says the skills work with any model. MIT licensed.
