Real calls

Model calls stream through a local sidecar, with tools gated by capability and consent checks.

Real state

Memory, transcripts, spend records, tasks and schedules persist on disk.

Real separation

Agents run concurrently with separate workspaces and bounded permissions.

What it does not simulate

Revenue, completed work, model activity, or spend. That list is the project's own, and keys stay in the OS keychain rather than the frontend. MIT licensed, with Windows described as the most-tested desktop target.
