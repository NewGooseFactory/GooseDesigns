TypeScript library · Effect 4.x is LTS

Each digit of the version says what is allowed to break.

Effect is a library for building robust, type-safe, production-grade applications in TypeScript — typed errors, dependency injection, structured concurrency, scheduling, tracing and schema validation. Teams run it in systems they expect to keep for years, so the release contract is written down.
