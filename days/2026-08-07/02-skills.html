Directory shape is illustrative. The project describes itself as skills straight from the author's .agents directory.

The claim

A skill you use daily and a skill you wrote for a README are not the same document.

Why it matters

Most published agent guidance is written to be read. It gets tidied, generalized, and stripped of the specific decisions that made it useful in the first place.

A working .agents directory has the opposite problem, and that is the point. It is messy in the places where the real judgment lives, and it carries the exact wording that made an agent behave the way its author wanted.

Publishing that directory is a stronger claim than publishing a guide. The author has to live with whatever is in it.

For anyone building their own skill library, the value is in seeing which decisions were worth writing down at all.
