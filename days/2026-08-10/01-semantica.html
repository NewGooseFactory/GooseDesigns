Node and edge names are a schematic drawing, not project API. The project describes graph-native infrastructure for context and accountable AI systems.

A

Graph-native, not graph-flavored

Context stored as nodes and edges keeps its shape, so a later question can travel the same path the first answer took.

B

Accountability needs an edge

An answer you can trace beats an answer you have to trust, and tracing requires the link to have been recorded at write time.

C

Infrastructure, stated plainly

The project calls itself infrastructure, which is a claim about what other systems sit on top rather than about a single application.
