One command is the whole interface

No account, no config file, no model picker. A single invocation that reads the machine and answers, which is the smallest surface a tool like this could have.

Rust for a hardware probe

Reading memory, GPU, and driver details across three operating systems is the kind of job where a single static binary saves more trouble than the language choice costs.

What is not on this page

No model names, no provider list, no memory thresholds, no quantisation. The trending description is two sentences and names none of it.
