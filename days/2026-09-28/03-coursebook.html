A process is an instance of a running program, and the kernel keeps a record for each one. Processes are created by copying an existing process.

Illustrative — the same claim, with apparatus

A process is an instance of a running program, and the kernel keeps a record for each one.1 Processes are created by copying an existing process2 — see extended reading.

1 citation · 2 footnote: the copy is lazy in practice. Terms in italics resolve in the glossary.
