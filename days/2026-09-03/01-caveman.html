The bit is the mechanism

Grammar is the part of your prompt the model was never billed for.

$add skill caveman
github.com/JuliusBrussee/caveman

Articles, auxiliaries, and politeness all cost tokens and carry almost no instruction. caveman drops them on purpose, which turns a joke about speech into a straightforward compression pass over the prompt.

Comprehension is the risk

Dropping function words saves tokens right up to the point where an instruction becomes ambiguous. The interesting question is where that line sits, and the description does not say.

A skill, not a wrapper

Shipping this as a Claude Code skill means it runs inside the agent rather than in front of it, so the compression applies to what the agent writes as well as what you type.

What is not on this page

No benchmark, no task set, no quality comparison, no failure rate. The trending description publishes one percentage and nothing else.
